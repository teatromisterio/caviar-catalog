# Каталог коллекций iPhone Duo (Caviar)

Статичная страница-каталог: коллекции → модели → полноэкранный просмотр, избранное с копированием идентификаторов.

## Структура
```
index.html          — вся страница (HTML + CSS + JS, данные каталога внутри)
assets/<коллекция>/ — cover.webp (обложка), NN.webp (полное, ≤1500px), NN-t.webp (превью 600px)
```

## Функции
- Главная: обложки коллекций с подписью → клик открывает каталог коллекции.
- В коллекции и на главной — кнопка «Посмотреть все модели»: сплошной каталог с фильтром по коллекциям и поиском по названию/ID.
- Сердечко на плитке и в полноэкранном режиме → избранное (счётчик в меню). Хранится в localStorage браузера.
- Избранное: «Скопировать идентификаторы» — строки вида `KAM-07 — Камея Весов — коллекция «Камеи зодиака», модель №7`; «Только ID» — `KAM-07, ZOL-12`.
- Клик по ID на плитке копирует строку модели.
- **Паки** — собственные подборки пользователя, до 3 одновременно. Кнопка-стопка на плитке и в полноэкранном просмотре открывает выбор пака; там же можно создать новый (модель сразу попадёт в него). Модель может быть в нескольких паках, цветные точки на фото показывают, в каких. Страница «Паки» в меню: 3 слота, открыть / скопировать ID / удалить; на странице пака — переименование, очистка, копирование строк и «Только ID». Хранится в localStorage (`caviar-duo-packs`).
- Полноэкранный просмотр: стрелки/свайп, клик по изображению — увеличение до полного размера, Esc — закрыть, F — в избранное.
- Адреса страниц через hash (`#/c/cameo`, `#/all`, `#/favorites`) — работают на GitHub Pages без настройки.

## Публикация на GitHub Pages
1. Создайте репозиторий, загрузите содержимое папки (index.html + assets/) в корень.
2. Settings → Pages → Source: Deploy from a branch → `main` / `root`.
3. Страница откроется по адресу `https://<user>.github.io/<repo>/`.

## Как добавить модель или коллекцию
1. Сохраните изображения в webp: полное (длинная сторона ≤1500px, quality 85) как `NN.webp` и превью 600px как `NN-t.webp`.
2. В `index.html` в массиве `COLLECTIONS` допишите название в `models` (порядок = номер).
3. Новая коллекция: добавьте объект `{slug, code, title, folder, desc, models}` и строку в `ASSET_DIR`.
   Не меняйте порядок существующих моделей — иначе сдвинутся ID, уже сохранённые в избранном.

## Дизайн
По гайдлайну страниц Caviar (Notion → Knowledge → «Скиллы и файлы для проекта Caviar»): шрифт Nunito Sans, золото `#A89974` / hover `#968758` / на светлом `#85764F`, фон `#F7F7F7`, текст `#393838`, чёрный `#0D1117`, отступы 64/40/24/14, H2 700 uppercase, статистика 800 золотом, webp-ассеты, `prefers-reduced-motion`, `<noscript>`.
